## 🚀 How to Use (For Users)

### Step 1: Visit Project Creation Guide
- Go to: Dashboard → Projects → Click "Guide" button
- Browse all 13 fields to find yours
- Read the guidance, examples, and tips

### Step 2: Create New Project
- Click "Add Project" button
- **Select your profession** from dropdown
- Form will automatically adapt with profession-specific guidance
- Labels, help text, and placeholders update in real-time

### Step 3: Fill Out Form
- **Title**: Be specific. Use the examples as inspiration.
- **Role**: Explain your specific contribution and expertise
- **Link**: Add GitHub, live demo, publication, or proof link
- **Description**: Tell the story: Problem → Solution → Impact
- **Gallery**: Upload 3-6 files (images, PDFs, documents) that prove your work

### Step 4: Upload Files
- Click "Add File" button in the gallery section
- Select images or PDFs from your computer
- See previews of files before submitting
- Max 10MB per file
- Can upload as many files as needed

### Step 5: Submit
- Form validates all required fields
- Shows clear error messages if anything is wrong
- Click "Save Details" to create project
- Success! Your project is now on your profile

## 💡 Pro Tips for Each Field

### 💻 Software Engineers
- Include GitHub link or live demo URL
- List exact technologies (not just "Python" but "Python 3.10 + FastAPI + PostgreSQL")
- Show metrics: request throughput, latency improvements, user count
- Upload architecture diagrams and performance graphs

### 🏥 Healthcare Professionals
- Include publication link (PubMed DOI, journal)
- Explain patient cohort size and demographics
- Include statistical significance (p-values)
- Upload research papers and clinical data visualizations

### 🎨 Designers
- Link to interactive Figma prototype or live website
- Show before/after comparisons
- Explain user research that led to design decisions
- Upload high-resolution mockups (2400px+ for retina)

### 🏗️ Architects
- Show project scale (sqft, cost, timeline)
- Explain innovation and sustainability features
- Include renderings, floor plans, and completed photos
- List certifications (LEED, WELL, ADA)

### ⚖️ Lawyers
- Only share publicly available case information
- Redact sensitive client details for confidentiality
- Link to court records or press coverage
- Explain the legal precedent set by case
